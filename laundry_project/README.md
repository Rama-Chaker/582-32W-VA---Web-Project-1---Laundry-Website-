# Violetta Laundry Project
## Overview
This project is a website designed for a local laundry and dry cleaning business in Lebanon, called Violetta Laundry. 
It presents core services, promotional offers, store location, contact information and schedule whether a delivery or pickup option in a clear, accessible structure for users.
Main clients are: Individuals and Hotels.
Color Palette: ![Color Palette Image](colorPalette.png)
#4A2E7A , #EBF3FE , #DFD4FF , #64748B , white and black
Fonts: Poppins and Inter

## ✨ Features
- **Landing Page:** This is the page where it will attract the clients that visit the website.
- **Our Services Page:** This is the page where it will states the Laundry's services.
- **About Us Page:** This is the page where it tell the clients more about Violetta Laundry.
- **Pricings Page:** This is the page where it will list the pricings.
- **Contact Page:** This is the page where it will help the clients to reach the Laundry out.
- **Pickup Page:** This is the page where the client has to fill it if he chose pickup.
- **Delivery Page:** This is the page where the client has to fill it if he chose delivery.
- **Admin Page:** This is the page where it will have like a "dashboard" for the admin to keep track of the laundry's progress.
- **User Page:** This is the page where it will be reserved to the client to track the orders, see order history...
